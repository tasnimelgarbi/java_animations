# Mug Drawing

## Overview

This project renders a 2D illustration of a coffee mug using basic Java Swing shapes and colors.

## Features

- 2D static drawing of a coffee mug using ovals and arcs.
- Simple layout and color design using Java AWT graphics.

## How to Run

```bash
javac -d build $(find . -name "*.java")
java -cp build mug.MugDemo
