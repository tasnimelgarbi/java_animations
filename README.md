# House Drawing

## Overview

This project renders a simple 2D house scene using Java Swing. The drawing includes a cartoon-style house, sky background, and decorative elements.

## Features

- Static 2D house drawing using basic shapes
- Elements include house body, roof, door, windows, and smoke

## How to Run

```bash
javac -d build $(find . -name "*.java")
java -cp build house.HouseAnimation
